# Материалы курса для домашнего задания 3

В каталоге находятся 14 PDF, соответствующих 13 лекциям: лекция №6 присутствует в двух копиях. Просмотрена структура курса и текст профильной лекции №13. Текст некоторых слайдов других лекций ограничен, поскольку содержание находится в изображениях; полный визуальный разбор всего курса для этой задачи не проводился.

## Нужные разделы лекции №13

| Слайды | Содержание | Применение в решении |
| --- | --- | --- |
| 25–27 | V2 protocol: health, metadata, inference | Проверки готовности; HTTP/gRPC-клиенты |
| 30–31 | initialize, execute, finalize; config.pbtxt | Python backend и lifecycle метрик |
| 33–35 | Ensemble и BLS | BLS понадобится при выборе другого backend с Python-прокси для метрик |
| 38–39 | Батчинг запросов | Объединение входов разных запросов в один вызов модели |
| 40 | Performance Analyzer | Отдельный SDK-контейнер и замеры под нагрузкой |
| 41–43 | Model Analyzer; режимы поиска, конфигурация | Ручной перебор ограниченного пространства на CPU |
| 44–46 | Сравнение вариантов по throughput, p99 и ресурсам | Таблицы и обоснование финального выбора |

В лекции №13 показан пример с ResNet50 на GPU. Его показатели производительности относятся к лекционному эксперименту; переносить их в отчёт MobileNet на другой машине нельзя. Условие домашнего задания отдельно требует COUNTER и GAUGE — эти детали уточнены по официальной документации Python backend.

Лекция №4, слайды 41–43: классификатор состоит из backbone и головы; выход головы — логиты, вероятности получаются через softmax. В качестве backbone перечислены ResNet, MobileNet, EfficientNet, ViT и SWIN. Это поддерживает выбор небольшого предобученного MobileNet для serving без отдельного обучения.

## Карта остальных лекций

1. Изображения как данные, обработка и основы CV.
2. Видео: контейнеры/кодеки, чтение и запись, CPU/GPU-инструменты.
3. Архитектуры нейросетей, обучение, подготовка датасета.
4. Классификация, transfer learning, оценка и интерпретация.
5. Metric learning: contrastive/triplet loss, ArcFace, поиск эмбеддингов.
6. CLIP, contrastive learning; DINO и self-distillation.
7. Детекция: R-CNN/SSD/YOLO/DETR, IoU и mAP.
8. Сегментация: FCN/U-Net, Dice/IoU, SAM.
9. OCR: детекция и распознавание, CTC, CER.
10. Генеративные модели: AE/VAE, GAN, AR, диффузия.
11. Диффузия: DDPM/DDIM, flow matching, Stable Diffusion, DiT, conditioning.
12. Мультимодальные модели: LLaVA, BLIP-2, VLM и ограничения.
13. MLOps: хранение/версионирование, MLflow, serving, Triton и оптимизация.
